# Campus Relay Adventure

A simple CLI choose-your-own-adventure game built for the MLH Global Hack Week challenge **Use GitHub Copilot to Build a Simple Application**.

## Run

```bash
python adventure.py
```

## What it does

You pick doors (Cursor / Tiger / Grok) and branch through short story choices until you complete a challenge path.

## Built with

- Python
- GitHub Copilot (prompting for scenes, choices, and structure)
